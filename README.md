# Своя игра

Локальная викторина для школьных и командных игр.

## Как это работает

- Учитель запускает игру на компьютере с Windows.
- Участники подключаются из браузера по локальной сети.
- Участникам не нужны установка и доступ в интернет.

## Скачать и запустить

Готовые версии будут опубликованы в [разделе релизов](https://github.com/Rattlhead/MyGamve-releases/releases).

1. Скачайте архив последнего релиза и распакуйте его целиком.
2. Запустите `SvoyaIgra.exe` на компьютере учителя.
3. Откройте адрес учителя из локальной сети. Сервер покажет его после запуска.

Этот репозиторий содержит только публичную справку и готовые релизы.
